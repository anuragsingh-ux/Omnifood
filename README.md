# 🍽️ Omnifood – Responsive Food Ordering Website

A modern, fully responsive landing page for a fictional food delivery service, built using **HTML**, **CSS**, and **JavaScript**. The project showcases layout structuring, mobile-first design, animations, and interactive UI elements.

---

## 🌐 Live Demo

👉 [Click to View Live](https://anurag-omnifood.vercel.app/)

---

## 🛠️ Tech Stack

| Technology     | Purpose                              |
|----------------|--------------------------------------|
| **HTML**      | Markup and semantic structure        |
| **CSS**       | Styling, Flexbox, Grid, animations   |
| **JavaScript** | DOM manipulation, interactions       |
| **Git & GitHub** | Version control and code hosting  |
| **Vercal** | Live deployment         |

---

## ✨ Features

- ✅ Fully responsive layout – mobile-first design
- ✅ Smooth scroll and UI animations
- ✅ Clean, accessible code using semantic HTML
- ✅ Interactive buttons and navigation
- ✅ Designed with Flexbox, Grid, and modern CSS techniques

---

## 🚀 Getting Started

To run the project locally:

### Clone the repository
git clone https://github.com/anuragsingh-ux/Omnifood.git

### Navigate to project folder
cd Omnifood

### Open index.html in your browser
(no build tools needed)
